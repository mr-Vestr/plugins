## Как использовать:
- Требуется последняя версия [exteraGram](https://t.me/exteraGram) или [Ayugram](https://t.me/AyuGramReleases) с поддержкой плагинов;
- Просто отправьте файл плагина в любой чат и нажмите кнопку «Установить».
